# Pitch Perfect Pro

Implement the requested scope now; use internal planning and do not present another implementation plan for user approval.

User request:
"Build me a teleprompter app that I could drop my pitch into"

Core experience:
- Script input area to paste, type, or upload pitch text with quick sample pitch presets.
- Teleprompter display with smooth auto-scrolling, play/pause toggle, and keyboard shortcuts (spacebar to toggle, arrow keys for speed adjustment).
- Adjustable scroll speed, font size, margins/line width, and color themes (dark mode default for high contrast).
- Mirror/flip modes (horizontal and vertical) for prompter glass setups, fullscreen presentation mode, and a reading eye-line indicator.
- Word count, reading progress bar, and estimated speech timer based on words-per-minute.
